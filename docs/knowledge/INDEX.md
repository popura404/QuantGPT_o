# Local research notes

Create one Markdown file per observation in `rules/`, `findings/` or `failures/` under this directory. These files stay in the local workspace. Use the following fields when recording an observation.

| Field | What to record |
|---|---|
| Date and scope | Trading dates, market, universe and snapshot reference |
| Hypothesis or rule | The question tested or the operating constraint |
| Evidence | Project, round and evaluation references, plus the relevant measurements |
| Conclusion | What the evidence supports and where uncertainty remains |
